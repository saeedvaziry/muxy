# Release Highlights

## Workflow

1. Identify the release version, tag, changelog range, or PR set from the user's request.
2. Inspect the available changelog entries and related PRs when needed.
3. Extract the most important improvements, fixes, and user-facing changes.
4. Group or rewrite related items into concise, readable bullets.
5. Omit PR numbers, author names, and low-value internal details.
6. Keep the final highlights short and focused on impact.

## Output

- Use bullet points.
- Focus on important improvements and fixes.
- Avoid PR numbers and contributor attribution.
- Keep wording polished and release-note ready.
